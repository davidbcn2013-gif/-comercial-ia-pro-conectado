# Backend Supabase

1. Crear un proyecto en Supabase.
2. Ejecutar `schema.sql` en SQL Editor.
3. Activar Email/Password en Authentication.
4. Crear el primer usuario administrador.
5. Insertar su perfil con `role='admin'`.
6. Configurar las variables de entorno del frontend:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`

No incluir nunca la service-role key en el frontend.
