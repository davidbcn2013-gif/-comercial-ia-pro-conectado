# Panel administrador

El administrador es el usuario cuyo `profiles.role` es `admin`.

Capacidades previstas:
- Ver comerciales.
- Activar/desactivar módulos por usuario.
- Mantener la configuración global de módulos.
- No modificar los datos privados de un comercial salvo que se añadan políticas explícitas de soporte.

Módulos iniciales:
- `cyc` — Crédito y Caución
- `map` — Prospección geográfica
- `routes` — Rutas comerciales

La UI principal solo muestra módulos habilitados para el usuario.
